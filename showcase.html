Open-Source Web Application Firewall Research

Comparative security research into open-source Web Application Firewalls and their behaviour against controlled web application attacks.

I worked with isolated Kali Linux and Ubuntu environments, vulnerable web applications, WAF configurations, security testing tools, and custom scripted testing to examine how malicious HTTP requests were detected or blocked.

Python Bash ModSecurity OWASP CRS NAXSI Coraza DVWA Kali Linux Ubuntu
What I worked with
  • Custom Python and Bash security-testing scripts
  • Controlled web application attack payloads
  • HTTP response and blocking behaviour analysis
  • WAF security alerts and rule analysis
  • Comparative testing across multiple WAFs
  • Isolated attacker and victim virtual machines
