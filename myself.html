My Journey

From building software to understanding how it breaks.

My interests have evolved over time, but software engineering remains the foundation behind everything I'm learning today.

💻
01 — Software Engineering

Where it started

My interest in technology eventually led me into Computer Science and software development. What initially fascinated me about websites grew into a much broader interest in building complete applications — from user interfaces and backend systems to APIs, databases, authentication, and deployment.

I completed my Bachelor of Science in Computer Science at BRAC University , and full-stack development became the area where I could turn ideas into working software.

Full-Stack Development Frontend Backend APIs Databases
🛡️
02 — Cybersecurity

Then I became interested in how software breaks.

Building applications made me increasingly curious about the other side of software: vulnerabilities, attack techniques, security controls, and what makes one application more resilient than another.

That interest led me to pursue a Master of Computing in Cyber Security in Australia. My studies and projects have allowed me to work with web application security, penetration testing, vulnerability assessment, network analysis, and defensive security concepts.

Application Security Penetration Testing Vulnerability Assessment Web Security
🔬
03 — Hands-On Security

Learning by testing real security controls.

One of my main areas of hands-on security work has been researching open-source Web Application Firewalls . I've built custom Python and Bash testing scripts, generated controlled web attacks, analysed HTTP behaviour and security alerts, and compared how different WAF implementations detect and block malicious requests.

This has been particularly interesting to me because it sits directly between my two areas of interest: understanding how web applications are built and understanding how they can be attacked and defended.

WAF Research Python Bash Security Testing HTTP Analysis
🟣
04 — What's Next

Connecting offensive and defensive security.

I'm continuing to expand beyond application security into areas such as Purple Teaming, detection engineering, intrusion detection, DFIR, and incident response.

I'm currently planning an end-to-end Purple Team security lab where I can explore the complete lifecycle from controlled attacks through monitoring, detection, investigation, and response.

Purple Teaming Detection Engineering DFIR Intrusion Detection Incident Response
